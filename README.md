The funniest possible last words a phone would say when its battery hits 1 percent — one line, one sentence, 127 characters. The phone knows it is about to die, says something only a dying phone would say, and the joke is in the voice, not in explaining the joke.

> Tell the charger I loved it, delete my browser history before anyone finds the 3 a.m. searches, and remember me at 100 percent.

## Run it

```sh
python3 main.py
```

This writes the line (no trailing newline) to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `/output` when unset), then prints the byte count, character count, and sha256. The program is deterministic — two runs produce byte-identical output — uses only the Python standard library, and makes no network calls.
